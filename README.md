# 🚀 FastAPI Practice

A collection of **FastAPI practice tasks and REST API exercises** created while learning FastAPI with Python.

## 🛠️ Technologies

- Python
- FastAPI
- Uvicorn
- Pydantic
- Postman

## 📚 Tasks & Questions

### Task 1
- Create a basic FastAPI application.
- Create a root endpoint.
- Return a simple response.

### Task 2
- Create API endpoints for mathematical operations.
- Implement multiplication and square operations.
- Use path/query parameters.

### Task 3
- Create a task management API.
- Add a new task using `POST`.
- Retrieve tasks using `GET`.

### Task 4
- Create a Student API.
- Use Pydantic models.
- Add, view, update, and delete student data.

### Task 5
- Create API endpoints using request parameters.
- Practice GET and POST methods.
- Handle API responses.

### Task 6
- Practice CRUD operations.
- Validate request data using Pydantic.
- Test APIs using Postman.

### Task 7
- Build a FastAPI application with multiple endpoints.
- Connect frontend and backend concepts.
- Test API requests and responses.

### Task 8
- Practice advanced FastAPI concepts.
- Create and test REST API endpoints.
- Improve API structure and validation.

## ▶️ Run the Project

```bash
pip install fastapi uvicorn
python -m uvicorn main:app --reload
```

Open the API documentation:

```text
http://127.0.0.1:8000/docs
```
